# 阶段 1：1MW 构网型 PMSG 风机机电耦合分析基准总结

生成时间：2026-06-11

## 1. 阶段目标

本阶段目标是先固定一套可运行、可分析、可出图的 1MW 构网型 PMSG 风机基准对象。该阶段不追求最终工程参数，而是验证完整论文实验链路：

```text
1MW 参数设定
-> 小信号模型建立
-> 扭振模态识别
-> 控制结构与参数扫描
-> 小扰动响应图
-> 非线性时域与频域验证
```

当前阶段已经具备初步论文图像成果，可以支撑阶段汇报。后续 2MW/5MW 参数替换应在本链路固定之后进行。

## 2. 当前基准对象

当前对象为 1MW 级 PMSG-WT，核心结构为：

```text
风轮/气动输入
-> 两质量块轴系
-> PMSG
-> 机侧变流器 MSC
-> 直流电容
-> 网侧变流器 GSC
-> LCL/电网
```

小信号侧已经包括：

- GFL-WT：MSC-MPPT，GSC-DVC + PLL
- GFM-GWT：MSC-MPPT，GSC-DVC + GFM
- GFM-MWT：MSC-DVC，GSC-GFM
- GFM-MWT+AD：MSC-DVC，GSC-GFM + APCAD
- TypeA / TypeC / TypeC+AD：用于分析 DC 电压控制位置和功率前馈的影响

非线性侧当前重点对象为：

- 模型：`Grid_FormingVSG_PMSG`
- 工作直流参考：`VdcRef = 1000 V`
- 当前控制结构更接近 TypeC 结构
- 后续仍需优先完成无扰动稳态、热启动和小扰动 FFT 验证

本阶段新增冻结版总说明：

- `Reports/Frozen_1MW_SmallSignal_Baseline_20260611.md`

## 3. 当前可以支持的核心结论

### 3.1 小信号模型不再只依赖特征值

现已补充小扰动响应图。小信号实验可同时展示：

- 特征值和阻尼比
- 参与因子
- 参数扫描下的模态移动轨迹
- 风速小阶跃/有功参考小阶跃下的 `omega_g`、`theta_tw`、`T_sh`、`v_dc`、`P_pcc` 响应
- `T_sh` 的低频频谱

这使得小信号结果可以和非线性时域响应、FFT 结果建立对应关系。

### 3.2 TypeC+AD 对轴系扭振具有可见阻尼效果

在 DVC Type 对比中，当前基准下：

| 模型 | 扭振频率 | 阻尼比 | 稳定性 |
|---|---:|---:|---|
| GFM-MWT-TypeA | 2.001 Hz | -0.0137 | 不稳定 |
| GFM-MWT-TypeC | 2.001 Hz | -0.0137 | 不稳定 |
| GFM-MWT-TypeC+AD | 1.954 Hz | 0.0116 | 稳定 |

这说明当前小信号层面可以支持如下表述：

```text
单纯改变 TypeA/TypeC 对当前轴系主导模态阻尼改善有限；
附加有功阻尼 APCAD 能显著改善该低频扭振模态阻尼。
```

### 3.3 非线性模型是下一步验证重点

当前小信号结果已经能够提出明确的非线性验证目标，但非线性模型仍不能作为最终证据直接使用。下一步应优先确认：

- 无扰动下三相电压、电流稳定；
- 有功功率维持在目标附近；
- DC 电压不持续发散，允许合理稳态偏差；
- `omega_t`、`omega_g`、`T_sh` 不发散；
- 能保存热启动文件；
- 小扰动后能从 `T_sh/omega_g/omega_t/P/iabc` 的 FFT 中观测到与小信号预测相近的低频模态。

因此，本阶段非线性部分应表述为“正在用于闭环验证的小信号对照对象”，而不是“已经完成最终稳定验证的非线性基准”。

## 4. 需要谨慎表述的地方

### 4.1 当前 1MW 参数仍是阶段性基准

当前参数不是最终工程参数。尤其是：

- 风轮侧惯量 `J_t = 8 * J_g`
- 轴系刚度 `K_sh` 由目标频率反推
- 轴系阻尼 `D_sh` 由假定阻尼比反推
- 气动阻尼和风速增益使用简化线性化
- 小信号 `Vdc = 1500 V` 与非线性工作基线 `VdcRef = 1000 V` 仍需进一步统一说明

因此论文中应写为：

```text
本文首先构建 1MW 级算例验证建模与分析流程；
后续将进一步替换为文献或工程给定的 2MW/5MW 参数。
```

### 4.2 小信号完整模型存在高频/非目标模态

完整状态空间直接 `lsim` 会被高频或非目标快速模态支配。因此当前小扰动响应图默认采用 `0-10 Hz` 低频模态截断响应，目的是展示机电耦合频段的响应。这一点应在论文图注或方法说明中交代。

建议表述：

```text
为突出机电耦合频段，本节小扰动响应采用低频模态截断方法，保留 0-10 Hz 范围内的模态，用于观察轴系相关响应。
完整模型稳定性仍通过特征值最大实部和非线性仿真单独评估。
```

## 5. 阶段 1 已完成项

- 已固定当前 1MW 参数基线。
- 小信号模型已覆盖 GFL、GFM-GWT、GFM-MWT、GFM-MWT+AD。
- 已补充 TypeA、TypeC、TypeC+AD 对比。
- 已完成 SCR、XR、Cdc、控制参数、阻尼控制参数的部分扫描。
- 已新增小扰动响应图。
- 非线性模型已进入 1000V 基准整定与验证阶段，但无扰动稳态、热启动和小扰动 FFT 对应关系仍需继续收敛。
- 已形成可用于阶段汇报的图像清单。

## 6. 阶段 1 后的直接建议

下一步建议不要马上替换 5MW，而是先做两件事：

1. 先完成 GFM-MWT 非线性无扰动稳态和热启动文件。
2. 用当前 1MW 基准补一张“小信号模态频率 vs 非线性 FFT 峰值”的对应图。
3. 稳定基准明确后，再搭建或整理 GFL 非线性对照组。

这样能把论文主线从“模型跑通”推进到“因果链条成立”。
