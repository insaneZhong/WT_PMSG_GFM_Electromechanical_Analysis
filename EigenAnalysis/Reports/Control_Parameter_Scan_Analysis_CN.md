# GFM 风电机组控制参数稳定域扫描分析

## 1. 分析目的

在四拓扑对照已经表明 `GFM-MWT` 的 2 Hz 机电扭振阻尼低于 `GFM-GWT`、APCAD 能改善目标扭振模态之后，本阶段进一步扫描以下构网控制参数：

| 参数组 | 物理含义 | 分析问题 |
| --- | --- | --- |
| `h`, `mp` | VSG 虚拟惯量与有功-频率下垂 | GFM 有功同步参数是否改变机电扭振及全系统稳定性 |
| `k_pdc`, `k_idc` | MSC 直流电压控制器参数 | 直流链到电磁转矩的耦合通道是否可通过整定减弱 |
| `k_pq`, `k_iq` | GSC 无功/电压控制相关参数 | 无功电压环是否引入或放大不稳定模态 |
| `K_damp` | APCAD 附加阻尼增益 | 目标 2 Hz 扭振阻尼可提高到何种程度 |

分析文件为 `Scan_GFM_Control_Parameters.mlx`，同时考察：

- `GFM-MWT`：`MSC-DVC, GSC-GFM`；
- `GFM-MWT+AD`：`MSC-DVC, GSC-GFM + APCAD`。

二维参数组均按照基准参数的 `0.01` 至 `100` 倍、每轴 31 点扫描；`K_damp` 按 `-1.5e7` 至 `5e6`、121 点扫描。

## 2. 基准工况

| 模型 | 扭振频率 (Hz) | 扭振阻尼比 | 扭振极点实部 (1/s) | 全系统最大实部 (1/s) | 全系统稳定 |
| --- | ---: | ---: | ---: | ---: | --- |
| `GFM-MWT` | 1.99729 | 0.00717 | -0.09001 | +0.005066 | 否 |
| `GFM-MWT+AD` | 1.98597 | 0.01562 | -0.19496 | +0.005095 | 否 |

APCAD 已使目标扭振模态的阻尼比提高约 `118%`，但两个模型在基准工况下均存在一个很慢的右半平面极点，因此“扭振模态改善”与“全系统稳定”必须分开表述。

## 3. 关键诊断：当前不稳定不是 2 Hz 扭振失稳

基准工况下最大实部对应的是 `0 Hz` 的非振荡慢模态，而不是约 `2 Hz` 的扭振模态。

| 模型 | 主导不稳定模态状态 | 参与度 |
| --- | --- | ---: |
| `GFM-MWT` | `omega_t` | 0.88889 |
| `GFM-MWT` | `omega_g` | 0.11111 |
| `GFM-MWT+AD` | `omega_t` | 0.88391 |
| `GFM-MWT+AD` | `omega_g` | 0.11049 |
| `GFM-MWT+AD` | `x_bp1` | 0.00559 |

而目标扭振模态仍由 `theta_tw`、`omega_g` 和 `omega_t` 主导。

这一结果表明，当前右半平面慢模态主要是传动链的共同转速/刚体运动模态，不是直流电压积分器或 APCAD 引起的目标频带振荡。当前模型中 `T_m` 被作为外部独立输入，`GFM-MWT` 的 MSC 又承担 DVC 而不再提供 MPPT 转矩-转速反馈，因此刚体转速模态缺少实际风机应具有的气动转矩斜率、转速调节或桨距控制反馈。

## 4. `h-mp` 扫描结果

| 模型 | 稳定点数量 | 最大实部最小值 (1/s) | 扭振阻尼范围 |
| --- | ---: | ---: | --- |
| `GFM-MWT` | 0 / 961 | +0.005066 | 基本固定为 0.00717 |
| `GFM-MWT+AD` | 0 / 961 | +0.005093 | -0.14839 至 0.11985 |

解释如下：

1. 未加 APCAD 时，`h` 与 `mp` 对 2 Hz 轴系扭振阻尼几乎没有影响，说明该扭振模态主要由机侧 DVC-电磁转矩-传动链路径决定。
2. 加入 APCAD 后，`h` 与 `mp` 会影响附加阻尼通道的相位与作用强度，因而扭振阻尼变化明显；某些极端组合甚至使目标扭振阻尼为负。
3. 即使选择扭振阻尼较高的 `h-mp` 组合，也仍不能清除 `0 Hz` 机械慢不稳定极点。

## 5. `k_pdc-k_idc` 扫描结果

| 模型 | 稳定点数量 | 最大实部最小值 (1/s) | 扭振阻尼范围 |
| --- | ---: | ---: | --- |
| `GFM-MWT` | 0 / 961 | +0.005066 | -0.00245 至 0.01858 |
| `GFM-MWT+AD` | 0 / 961 | +0.005095 | -0.01097 至 0.06317 |

该参数组对目标扭振最敏感。原因是 `GFM-MWT` 中直流电压控制在机侧实施，`v_dc` 误差直接改变 PMSG 电流指令和电磁转矩；因此调整 DVC 增益能够改变轴系获得的电气阻尼。

但扫描结果也给出一个边界：单独调整 `k_pdc/k_idc` 无法让全系统稳定，说明 DVC 虽然是扭振耦合强度的重要调节量，却不是当前 `0 Hz` 慢不稳定模态的根本稳定机制。

## 6. `k_pq-k_iq` 扫描结果

| 模型 | 稳定点数量 | 最大实部最小值 (1/s) | 扭振阻尼范围 |
| --- | ---: | ---: | --- |
| `GFM-MWT` | 0 / 961 | +0.005066 | 基本固定为 0.00717 |
| `GFM-MWT+AD` | 0 / 961 | +0.005095 | 0.01478 至 0.01616 |

无功/电压控制环对未加 APCAD 的 2 Hz 扭振影响很小，表明它不是当前机电耦合的主通道。但当 `k_pq` 或 `k_iq` 过高时，全系统最大实部可快速增大，说明该控制环仍需要作为电气稳定性约束加以整定。

因此在论文中可将该结果表述为：无功/电压环主要影响电气稳定边界，而机侧 DVC 主要影响目标轴系扭振阻尼。

## 7. `K_damp` 扫描结果

| 工况 | `K_damp` | 扭振阻尼比 | 扭振极点实部 (1/s) | 全系统最大实部 (1/s) |
| --- | ---: | ---: | ---: | ---: |
| 当前基准 | `-5.0e6` | 0.01562 | -0.19496 | +0.005095 |
| 扭振阻尼最高扫描点 | `-1.5e7` | 0.03434 | -0.42204 | +0.005153 |
| 最大实部最小扫描点 | `+4.833e6` | -0.00040 | +0.00504 | +0.005039 |

负向 `K_damp` 可以持续推动 2 Hz 扭振极点左移，提高目标模态阻尼。然而，令最大实部稍微减小的正向增益会使目标扭振模态接近失稳。这再次证明：APCAD 可用于抑制 2 Hz 扭振，但不应承担稳定机械刚体转速模态的任务。

## 8. 当前可以形成的研究结论

1. `GFM-MWT` 的目标机电扭振主要受机侧 DVC 参数影响；`k_pdc/k_idc` 应作为阻尼控制设计的重点联合整定参数。
2. APCAD 对约 2 Hz 扭振提供有效阻尼，当前 `K_damp=-5e6` 已有改善作用；继续增大负向增益可进一步提高目标阻尼，但需在完整非线性模型中检验控制饱和和瞬态功率冲击。
3. `h/mp` 与 `k_pq/k_iq` 必须纳入稳定域约束，但在当前模型中并不是未加阻尼时轴系扭振增强的主要原因。
4. 当前所有控制参数扫描均未消除主导 `0 Hz` 慢不稳定极点，根本原因指向机械侧共同转速调节机制缺失，而非仅仅是控制增益没有调好。

## 9. 下一步必须补充的模型环节

在继续宣称 `GFM-MWT` 的全系统稳定性或进入非线性验证之前，应为机侧 DVC 架构补充实际风机的转速平衡机制。推荐优先增加以下至少一项：

1. 气动转矩线性化：将 `T_m` 建模为风速和风轮转速的小扰动函数，引入工作点处的 `dT_m/domega_t` 气动阻尼项。
2. 上层转速/功率控制：在 `MSC-DVC` 条件下，为能量与转速平衡设置慢速参考调节通道，而不是将机械输入扭矩完全视为固定外扰。
3. 变桨控制模型：在额定以上或需要限制转速的工况下，引入桨距角控制及其执行器动态。

补入该机械侧反馈后，应重新运行本扫描脚本。如果 `MaxReal` 转为负值，再在稳定域内选择 `k_pdc/k_idc` 与 `K_damp` 的折中组合，并进入 Simulink 时域和 RT-LAB 半实物验证。
