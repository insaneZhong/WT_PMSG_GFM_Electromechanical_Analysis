# Grid_Forming_PMSG1 无气动基准模型诊断结论

## 1. 本次目的

本次只运行旧版 `Grid_Forming_PMSG1.mdl`，不加入气动模块、两质量块轴系、风速阶跃、故障和附加阻尼控制。目的不是证明新模型已经稳定，而是确认旧版电气基准模型本身能否建立 1 MW 无扰动稳态。

## 2. 原模型工作方式

- PMSM `mode=0`。
- PMSM 机械模型内部开关条件为 `mode > 0.1`。
- 当 `mode=0` 时，机械速度由 `Speedin=10*2*pi/20=pi rad/s` 强制给定，即约 `30 rpm`。
- 原模型中的 `TL` Ramp 虽然由 `0` 增长并饱和到 `9.55`，但在 `mode=0` 下不是当前主导机械输入。
- 直流电容为 `Cdc=1500 uF`，初始电压为 `1000 V`。
- 机侧 DC-link 电压参考为 `1200 V`。
- GFM 预同步标志不是根据电压、相位和频率误差闭环判断，而是在 C 代码中由时间直接切换：

```c
if (system_Time < PRESYN_SWITCH_TIME) Pre_syn = 0;
if (system_Time > PRESYN_SWITCH_TIME) Pre_syn = 1;
```

当前 `PRESYN_SWITCH_TIME=2 s`。

## 3. 仿真证据

使用 `diagnose_grid_forming_pmsg1_no_aero.m` 临时挂接观测块，不保存、不覆盖原 `.mdl` 文件。

为了避免旧 MEX 全局变量残留，本结论只采用“重新编译 MEX 后”的干净仿真。

首先，把 `PRESYN_SWITCH_TIME` 临时覆盖为 `10 s`，只运行到 `2.5 s`，使网侧断路器保持断开。结果如下：

| 指标 | 结果 |
|---|---:|
| 并网状态 | 断路器保持断开 |
| `2.5 s` 末端 `Udc` | 约 `1200.8 V` |
| 末 1 秒 `Udc` 均值 | 约 `1199.9 V` |
| 末 1 秒 `Udc` 范围 | 约 `1197.9-1202.6 V` |
| 末 1 秒 `Udc` 斜率 | 约 `-0.12 V/s` |

然后恢复默认 `PRESYN_SWITCH_TIME=2 s`，重新编译并运行到 `2.5 s`。结果如下：

| 指标 | 结果 |
|---|---:|
| 并网标志上升沿 | `2.001 s` |
| 并网前 DC-link 均值 | 约 `1200 V` |
| `2.001 s` 有功功率 | 约 `0.010 MW` |
| `2.101 s` 有功功率 | 约 `-0.225 MW` |
| `2.5 s` 有功功率 | 约 `-1.199 MW` |
| `2.5 s` 末端 `Udc` | 约 `9051 V` |
| 末 1 秒 `Udc` 斜率 | 约 `4179 V/s` |

此前未清理 MEX 状态的长仿真只作为异常线索，不用于定量结论。干净重编译结果已经足以证明：失稳发生在网侧并网切换之后。

因此，旧版无气动模型的机侧 DC-link 可以独立稳定，但闭合网侧断路器后没有稳定在 1 MW 工作点。

## 4. 原因排序

### 已排除：机侧 DVC 独立运行并非首要故障点

在断路器保持断开的干净仿真中，DC-link 能稳定到约 `1200 V`。由于 `mode=0` 使用固定机械速度，旧模型的机侧 DVC、机侧电流环和 PWM 至少可以建立独立直流稳态。

### 原因 1：并网条件只是固定时刻切换

代码注释提出应检查频率误差、电压幅值误差和相角误差，但当前实现只按 `2 s` 时间切换。断路器在 DC-link 未稳定时闭合，导致明显冲击。

更准确地说：即使 DC-link 已基本稳定，当前固定时刻切换也没有验证 PCC 电压幅值、相位和频率误差是否满足安全闭合条件。

### 原因 2：网侧闭环在并网后不能维持功率与 DC-link 能量平衡

并网后约 `0.5 s` 内，`Udc` 已升至约 `9051 V`，而 `Pmeas` 变为约 `-1.199 MW`。这说明网侧功率方向、P-f 环、电压环、电流环和饱和处理需要继续逐项检查。

在一次异常观测中，`2.0-2.05 s`：

- `Id_ref` 约为 `1500 A`；
- `Iq_ref` 约为 `-1500 A`；
- 实际 `Id` 最低约为 `-3659 A`。

说明网侧电压环、电流环和物理滤波器在闭合瞬间可能进入强饱和区，不能再用小信号稳态近似解释。

## 5. 与当前论文对象的差异

旧版 `Grid_Forming_PMSG1` 可作为调试参考，但不是当前“同一对象”模型：

| 参数 | 旧版 PMSG1 | 当前小信号统一对象 |
|---|---:|---:|
| 机械速度 | `pi rad/s`，约 `30 rpm` | `15.708 rad/s`，约 `150 rpm` |
| DC 电压参考 | `1200 V` | `1500 V` |
| DC 初始电压 | `1000 V` | 应进一步统一到运行点 |
| 气动/轴系 | 无 | 有两质量块轴系 |

## 6. 后续修复顺序

1. 将 DC 初始电压、DC 参考电压和小信号 `V_dc0` 统一。
2. 把 `Pre_syn` 从固定时间切换改成“最短等待时间 + DC-link、电压、频率和相角条件”。
3. 在固定速度、无气动条件下，检查网侧功率方向、P-f 环、电压环、电流环及抗积分饱和处理。
4. 先让旧版无气动电气基准在闭合断路器后稳定送出 1 MW。
5. 再把同样的电气侧修复带回含气动和两质量块的新模型。
