# 程序修改与使用说明（2026-05-29）

## 一、本次修改目标

本轮修改围绕一个主线展开：让小信号模型和非线性 Simulink/C 控制模型尽量描述同一个 1 MW 构网型直驱风机对象，并为后续“无扰动稳态 -> 稳态原因排查 -> 小扰动验证”建立可重复的运行流程。

当前重点不是直接加扰动或阻尼控制，而是先确认：

- 风机本体参数是否统一；
- 小信号 VSG 与非线性下垂/功率环是否能逐步同构；
- 非线性模型在无扰动下是否能稳定送出 1 MW；
- 若不能送出 1 MW，先定位是机械侧、DC-link、网侧功率环、电压环还是并网时序问题。

### 3. C 控制器中增加 VSG 等价频率环开关

修改文件：

- `grid_forming_control.h`
- `grid_forming_control.c`
- `schemeA_tuning_overrides.h`

当前 C 控制器原始结构是：

```text
P环 -> w_ref
Q下垂 -> 电压幅值
```

小信号模型中是 VSG 形式：

```text
2H*w0*dw/dt = P_ref - P - (w-w0)/mp
```

因此本轮在 C 侧增加了可开关的 VSG 等价频率环：

```c
#define ENABLE_VSG_EQUIV_WREF 0
```

默认值为 `0`，也就是仍然使用原来的功率环/下垂逻辑。  
当通过 `-DENABLE_SCHEMEA_OVERRIDES` 编译时，`schemeA_tuning_overrides.h` 会把它切到方案 A 逻辑，用于后续严格对应小信号 VSG。

说明：没有新增一个新的并网后 PLL。代码中已有的 `PLL_loop_pi` 是原始预同步 PLL，仅在 `Pre_syn == 0` 时使用，并网后应由 GFM 内部角度生成。

### 4. 无扰动稳态与根因排查脚本

- `run_single_point_steady_checks.m`

- `scan_steady_nondisturbance_voltage_loop.m`
- `scan_delivery_limits_no_disturbance.m`

这些脚本用于分阶段判断：

- 功率环、电压环、并网时序、限幅是否是瓶颈。

## 五、推荐的下一步研究顺序

当前建议继续按下面顺序推进：

1. 确认 `Pmeas_mean ≈ 0.607 MW` 的原因；
2. 增加内部输出：功率环输出、`Id_ref`、`Id`、电压环输出、限幅状态；
3. 判断是否是功率环输出限幅、电压环/电流环限幅、或者电压幅值控制通道限制；
4. 让无扰动工况先达到：

```text
Pmeas_mean -> 1 MW
Udc_slope  -> 0
OmegaG_slope -> 0
ThetaTw_slope -> 0
```

5. 达到稳态后，才加入小扰动验证；
6. 最后再接入阻尼控制或 APCAD 验证。

## 六、注意事项

- 不要先加风速阶跃；
- 不要先加故障；
- 不要先加阻尼控制；
- 不要直接以 `pcc_uab/pcc_ia` 自算功率作为主判据，当前模型里该通道可能存在量纲/缩放差异；
- 目前主功率判据优先使用 `pmeas_out`；
- 如果 MATLAB 报 `dtime` 或 `Ts_step` 不存在，说明模型 `InitFcn` 没有正常执行，需要重新打开模型或运行初始化。
