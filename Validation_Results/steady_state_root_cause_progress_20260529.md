# 无扰动稳态排查进展（2026-05-29）

## 已完成的关键动作
1. 统一小信号与非线性“同一对象参数”（机械/轴系已对齐）。  
2. 四模型小信号重跑，轴系主导振荡点仍在约 2 Hz。  
3. 非线性无扰动诊断脚本固化：`run_no_disturbance_diagnosis.m`。  
4. 针对 C 网侧有功环做单行方向试验：  
   - `grid_forming_control.c` 中  
   - `p->pf.w_ref = 314 + power_loop_pi.Out;`  
   - 改为 `p->pf.w_ref = 314 - power_loop_pi.Out;`

## 关键证据
- 原始工况（未修正前）长期表现为：`Ppcc < 0`、`Udc` 持续抬升。  
- 单行方向修正后，在部分无扰动组合下 `Pmeas/Ppcc` 可以翻为正值（已观察到正送功），说明“有功环方向”是核心问题之一。  
- `ReferenceDCVoltage` 从 `1200` 提升到 `5000` 后，`Udc` 能在 5kV 附近工作，表明当前模型中 DC 量纲/标定与 1200V 参考不匹配。
- 强制断路器闭合对结果有影响但不是主因；主因仍在有功-直流平衡链路。

## 当前结论
1. 非线性稳态不稳的主矛盾已从“纯参数问题”收敛到“控制方向 + 量纲标定 + 环路耦合”。  
2. 仅靠 PI 数值替换（不改方向与标定）无法把系统拉到 1MW 稳态送功。  
3. 下一步应优先做：
   - 固化网侧有功环方向修正；
   - 统一并确认 DC 电压参考与测量标定（1200 vs 5000 对应关系）；
   - 在此基础上再做 Scheme A 参数回填与 VSG 结构统一。
