# 构网型风电机组机电耦合分析主程序使用说明

主入口：

```matlab
cd('D:\博士工作\论文工作\（1）构网型风电机组\构网型风电机组\GFM_1MW _nonlinear')
run('main_GFM_MWT_Modular_Run.m')
```

## 1. 推荐运行顺序

第一步，打开：

```matlab
runCfg.stage1_sameObjectParams = true;
runCfg.stage1_smallSignalCompare = true;
```

作用是同步小信号参数、建立“同一对象参数表”、导出 Scheme A 控制器参数，并完成四拓扑小信号对照和 SCR/XR/Cdc 扫描。

第二步，打开：

```matlab
runCfg.stage2_noDisturbanceSteady = true;
```

作用是在不加风速阶跃、不加故障、不加阻尼验证的条件下，检查非线性模型是否能建立无扰动稳态。

第三步，打开：

```matlab
runCfg.stage3_rootCauseDiagnosis = true;
```

作用是排查 1 MW 功率能否送出。重点看机械侧是否稳定、`Pmeas` 是否接近 1 MW、`Udc_slope` 是否接近 0，以及 `wref/omega_g/theta_tw` 是否仍在漂移。

第四步，打开：

```matlab
runCfg.stage4_nonlinearFigures = true;
```

作用是把 Baseline 与 Scheme A 两类非线性仿真统一出图。

第五步，确认无扰动已经稳住后，再打开：

```matlab
runCfg.stage5_smallPerturbation = true;
```

作用是施加很小风速阶跃，做小扰动非线性验证。

## 2. 常改参数位置

系统扫描参数在主程序 `ssmCfg.sweeps` 中修改，例如：

```matlab
logspace(log10(1.25), log10(25), 40)  % SCR
linspace(1, 20, 40)                   % XR
```

非线性稳态参数在 `nlCfg` 和 `steadyCfg` 中修改，例如：

```matlab
nlCfg.pref = 1e6;
nlCfg.simStop = 3.0;
steadyCfg.prefList = [0.85e6, 1.0e6, 1.2e6];
```

小扰动参数在 `pertCfg` 中修改，例如：

```matlab
pertCfg.windStepMps = 0.10;
pertCfg.simStop = 5.0;
pertCfg.useSchemeA = true;
```

## 3. 结果目录

总控结果默认保存到：

```text
Validation_Results\Master_Run
```

小扰动结果保存到：

```text
Validation_Results\Small_Perturbation
```

## 4. 当前注意事项

`Parameters.m` 末尾包含 `clear all`，因此主程序和模块函数都避免直接在当前工作区运行它，而是读取生成后的 `Parameters.mat`。如果你手动改了 `Parameters.m`，建议先打开 `stage1_sameObjectParams` 重新同步。

非线性稳态还没有被证明完全达到 1 MW 稳态。当前流程的目的正是先让机械侧稳定，再排查 DC-link、GSC 功率环、电压环和并网时序。
