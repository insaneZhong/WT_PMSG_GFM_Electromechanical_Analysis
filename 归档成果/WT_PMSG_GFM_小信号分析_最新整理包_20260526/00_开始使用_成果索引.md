# 构网型风电机组机电耦合小信号分析：最新整理包

## 1. 本整理包定位

本文件夹是后续非线性验证工作的“小信号分析基线包”，用于集中保存此前已完成的：

- WT-PMSG 两质量块小信号模型；
- GFL/GFM 四拓扑因果对照模型；
- APCAD 附加阻尼模型；
- 参数扫描、模态轨迹和结果图表；
- 中文使用说明与最终研究报告。

本整理包采用复制归集方式生成，未移动或覆盖原始 Git 工作树。

## 4. 四拓扑模型对应关系

| 研究拓扑 | 控制结构 | 模型程序 |
| --- | --- | --- |
| `GFL-WT` | `MSC-MPPT, GSC-DVC + PLL` | `Generate_SSM/WT_PMSG_GFL_Model.mlx` |
| `GFM-GWT` | `MSC-MPPT, GSC-DVC + GFM` | `Generate_SSM/WT_PMSG_GFM_GWT_Model.mlx` |
| `GFM-MWT` | `MSC-DVC, GSC-GFM` | `Generate_SSM/WT_PMSG_VSG_Model.mlx` |
| `GFM-MWT+AD` | `MSC-DVC, GSC-GFM + APCAD` | `Generate_SSM/WT_PMSG_VSG_Damping_Model.mlx` |

说明：早期程序命名中使用了 `VSG`，在当前研究叙事中对应机侧采用 DVC、网侧采用 GFM/VSG 控制的 `GFM-MWT` 架构。

## 5. 建议执行顺序

1. 运行 `EigenAnalysis/Parameters.m`，检查并设置风机、电网、控制器和 APCAD 参数。
2. 在 `Generate_SSM/` 中依次生成四类模型对应的 `Unified_WT_PMSG_*.mat`。
3. 运行 `EigenAnalysis/Compare_Control_Mode_Four_Topologies.mlx`，得到四拓扑基准与工况扫描对比。
4. 运行 `EigenAnalysis/Track_GFM_Mode_Trajectories.m`，观察关键参数改变时约 `2 Hz` 机电扭振模态的移动轨迹。
5. 运行 `EigenAnalysis/Scan_GFM_Control_Parameters.mlx`，分析 `h`、`mp`、`k_pdc/k_idc`、`k_pq/k_iq` 与 `K_damp` 的稳定域和阻尼影响。

## 7. 与非线性模型工作的衔接

后续在 `D:\博士工作\论文工作\（1）构网型风电机组\构网型风电机组\GFM_1MW _nonlinear` 中开展 Simulink 非线性改造时，本整理包用于提供：

- 两质量块轴系及机电扭振目标频率的参数参考；
- `GFM-MWT` 与 `GFM-MWT+AD` 控制结构定义；
- APCAD 中心频率、阻尼增益方向和比较指标；
- 非线性仿真需要复现的小信号对照结论。

非线性模型完成后，应以相同工作点和参数重新比较：

- `omega_t`、`omega_g`、`theta_tw`、`T_sh`；
- `V_dc` 与有功功率响应；
- 约 `2 Hz` 分量的振荡衰减；
- APCAD 投入前后的阻尼改善效果。
